# Проект "Банковский виджет"

## Описание:

Проект "Банковские виджет" - это веб-приложение на Python
помогающее пользователю удобнее следить и управлять своими
финансами.

### Функции для защиты данных:

**get_mask_card_number** - функция скрывающая номер карты.
Принимает номер карты пользователя и возвращает его скрытый вариант.

**get_mask_account** - функция скрывающая номер счёта.
Аналогично первой функции, работает с номером счёта.

**mask_account_card** - продвинутый вариант первых двух функций,
проверяющий не только номер карты или счёта,
но и наличие пустого или некоректного ввода.

### Функции сортировки данных:

**filter_by_state** - функция фильтрующая данные по заданному значению.
Принимает данные о банковских операциях и возвращает только те, в которых
есть заданное значение (по умолчанию - по значению состояния "EXECUTED").

**sort_by_date** - функция сортирующая данные в заданном направлении.
Также принимает данные о банковских операциях,
но возвращает их отсортированными по заданному направлению
(по умолчанию - по убыванию).

**get_date** - функция форматирующая строку с датой.
Принимает строку с датой и временем и возвращает только дату в формате "дд.мм.гггг".

### Функции генераторы:

**filter_by_currency** - функция для поочерёдного вывода транзакций.  
Принимает данные о банковских транзакциях и поочерёдно возвращает их по
заданному значению валюты.

**transaction_descriptions** - функция для поочерёдного вывода описания транзакций.  
Также принимает данные о банковских транзакциях, но поочерёдно возвращает уже их описание.

**card_number_generator** - функция для генерации номера карты.  
Принимает начальное и конечное значение, и генерирует по ним номера карт.


## Установка:

1. Клонируйте репозиторий:

```
git clone git@github.com:Dmitriy-Logvinenko/bank-widget.git
```

2. Установите зависимости:

```
pip install -r requirements.txt
```

## Использование:

1. Откройте свой терминал.
2. Запустите проект с помощью одной из команд:

```
python src/decorators.py

python src/generators.py

python src/processing.py

python src/masks.py

python src/widget.py
```

## Тестирование:

В файле `test_decorators.py` тестируется декоратор `log` с помощью таких тестов как:
   - `test_log` - проверяет работу при успешном выполнении функции.
   - `test_zero_log` - проверяет возникновение ошибки при делении на ноль.
   - `test_log_incorrect` - проверяет ошибку при некорректно введённых данных.

В файле `test_generators.py` проверяются такие тесты как:
   - `test_filter_by_currency` - проверяет поочерёдный вывод транзакций.
   - `test_transaction_descriptions` - проверяет поочерёдный вывод описания транзакций.
   - `test_card_number_generator` - проверяет генерацию номеров карт.

В файле `test_masks.py` содержатся проверки на сокрытие данных:
   1. Для функции `get_mask_card_number`:
      - `test_get_mask_card_number` - проверяет работу функции при различных вариантах ввода.
      - `test_get_mask_card_number_len` - тестирует работу при некорректной длине номера карты.
      - `test_get_mask_card_number_correct` - проверяет корректность введённых данных.
   2. Для функции `get_mask_account`:
      - `test_get_mask_account` - проверяет работу функции при разных вариантах ввода.
      - `test_get_mask_account_no_isdigit` - проверяет работу при некорректном вводе.
      - `test_get_mask_account_len` - тестирует функцию при малой длине ввода.

В файле `test_processing.py` собраны следующие тесты:
   - `test_filter_by_state` - тестирует вывод данных при заданном значении.
   - `test_sort_by_date` - проверяет сортировку данных по заданному направлению.

Файл `test_widget.py` хранит тесты:
   - `test_mask_account_card` - тестирует работу функции `mask_account_card` при разных данных.
   - `test_mask_account_card_empty` - проверяет функцию на пустой ввод.
   - `test_mask_account_card_correct` - проверяет на корректность ввода.
   - `test_get_date` - тестирует фильтр даты.
